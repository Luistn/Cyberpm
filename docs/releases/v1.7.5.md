# Cyberpm 1.7 - release v1.7.5

Adiciona o botao **Hydra** ao lado de Sherlock. A janela independente permite selecionar o executavel, informar argumentos, acompanhar a saida e parar a execucao. O campo comeca com `-h` para mostrar a ajuda.

No Kali/Debian, instale o executavel com `sudo apt install hydra` se necessario.

Ao executar `cyberpm` no Kali, o atualizador existente instala esta release e reinicia a interface. Requer clone Git na branch `main`, origem oficial e acesso ao GitHub. Alteracoes locais sao preservadas em backup Git. Instalacoes por ZIP exigem atualizacao manual.

A interface exibe **1.7** e a tag tecnica e **v1.7.5**.
