# Cyberpm 1.24 — release v1.7.22

- Ao iniciar `cyberpm`, busca commits oficiais de `main` e aplica atualizações por fast-forward quando a instalação está limpa.
- Faz o fluxo de importação de CTF encaminhar os arquivos reconhecidos para a ferramenta e análise apropriadas.
- Inclui ações para reverter o XOR dinâmico de `crazyx0r`, extrair conteúdo de imagem com `steghide` e inspecionar o ELF de `broken` com GDB.
- Mantém o assistente contextual sob demanda e o manual completo em atalhos, sem iniciar o assistente automaticamente.

## Validação

Verificação de sintaxe Python aprovada. Os desafios externos e a instalação de ferramentas precisam ser conferidos no Kali.
