# Cyberpm 1.9 - release v1.7.7

- Menu lateral com atalhos para as ferramentas. Teste de senhas, sessao, rede e Telegram abrem em janelas independentes, preservando configuracoes ao fechar a janela.
- Mantem alvo e controles da auditoria no painel principal junto de progresso, fases e log.
- Corrige o tamanho da janela de login manual e preserva o motivo final quando uma lista e interrompida.
- HTTP 405 agora explica a recusa do metodo e orienta conferir o endpoint POST real no navegador. A lista continua parando em erro de configuracao; nao repete tentativas contra uma URL que recusa o metodo.
- Novo comando `cyberpm --reparar-navegador`: instala Playwright e Chromium em ambiente Python isolado e verifica o driver antes de usa-lo. Evita depender do pacote Node incompleto em /usr/share/nodejs/playwright.

Para o erro de navegador no Kali:

```bash
sudo apt install python3-venv python3-tk
cyberpm --reparar-navegador
```

Feche e abra o Cyberpm depois do reparo. Se houver dependencias nativas ausentes do Chromium, consulte o erro exibido no terminal. O reparo requer acesso a internet.

Validacao: 25 testes de runtime, parada por 405, layout, releases e atualizacao; previa visual aberta no Windows. A instalacao real do Playwright no Kali nao foi executada neste ambiente. Nenhum teste de senha foi enviado ao site informado.
