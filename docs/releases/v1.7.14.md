# Cyberpm 1.16

O Cyberpm consulta a cópia oficial do catálogo no GitHub se o servidor do CTF Lab recusar a importação pelo link.

Em outros CTFs, abra o desafio no navegador e baixe as evidências. Use **Importar CTF externo** para abrir o arquivo, o ZIP ou a pasta baixada e ler o enunciado e os anexos. O resultado é investigado localmente no Kali.
