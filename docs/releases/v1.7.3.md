# Cyberpm 1.5 — release v1.7.3

## Atualização automática ao iniciar

Antes de aplicar uma release oficial, o atualizador guarda alterações rastreadas e arquivos não rastreados em um stash Git. Depois de uma atualização bem-sucedida, o backup continua disponível com `git stash list` e pode ser revisado com `git stash show -p stash@{0}`. As alterações guardadas não são reaplicadas sobre os arquivos novos.

## Instalação de ferramentas ausentes

Se John the Ripper ou Sherlock não estiver instalado no Kali, o Cyberpm informa qual pacote falta e pede confirmação antes de abrir a autenticação do sistema (`pkexec`). A senha é digitada na janela do Kali e não é coletada pelo Cyberpm. John instala o pacote `john`; Sherlock instala o pacote Kali `sherlock` e inicia a busca informada após a instalação. As dependências das fases continuam sendo verificadas e instaladas durante a auditoria, respeitando a opção para não instalar ferramentas.
