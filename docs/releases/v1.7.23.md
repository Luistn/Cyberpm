# Cyberpm 1.25 — release v1.7.23

- A análise de IA na importação CTF agora funciona com evidências diversas: sugere a categoria, a ferramenta do Cyberpm, os passos seguintes e uma resposta quando os dados permitem recuperá-la.
- Um indicador pequeno mostra o estado da IA. A importação aguarda a pré-análise; se a chamada falhar, ainda é possível seguir manualmente.
- O contexto enviado à IA usa amostras limitadas e redigidas; os arquivos não são executados.
- O terminal GDB interativo ajuda a analisar ELF no próprio fluxo CTF e pode fornecer o contexto da sessão ao assistente aberto por atalho.
- Respostas reconhecidas pelo resolvedor XOR recebem identificação e destaque melhores.
- Corrigido o aviso Python de `return` em `finally` durante o encerramento de tarefas.

## Validação

Compilação dos módulos Python alterados aprovada. A execução de desafios e a instalação das ferramentas devem ser confirmadas no Kali.
