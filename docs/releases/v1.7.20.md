# Cyberpm 1.22 — release v1.7.20

- Corrige a flag do Dalfox e permite descoberta de parâmetros XSS quando a coleta inicial não encontra parâmetros.
- Inclui parâmetros GET opcionais de OpenAPI/Swagger nas entradas de SQLmap e XSS; amplia a revisão de API GET/OPTIONS para até 24 rotas.
- Prioriza parâmetros mais úteis no SQLmap, amplia a amostra de 5 para 10 URLs e usa crawl GET limitado quando não há parâmetros conhecidos.
- Corrige a lista de subdomínios e permite executar o perfil Bug Bounty sequencialmente nos subdomínios selecionados e autorizados.
- Amplia o limite padrão do Nuclei para 15 minutos e adiciona limites configuráveis para API, SQLmap e XSS.
- Adiciona **Achados / validar** à barra lateral, com ferramenta e evidência associadas.

## Validação

Testes automatizados não foram executados nesta publicação. A execução de scanners contra alvos deve ser feita somente dentro de escopo autorizado.
