# Cyberpm 1.2 — release de compatibilidade v1.6.5

## Atualização apenas ao chamar o programa

Quem está na v1.6.4 pode executar `cyberpm` para receber esta release, sem `git pull` manual. A tag técnica v1.6.5 e o arquivo VERSION foram escolhidos para compatibilidade com o cliente antigo. A interface continua exibindo 1.2; `cyberpm --versao` mostra também a release técnica.

A atualização exige instalação Git oficial em main, arquivos do programa sem alterações locais e acesso ao GitHub. A consulta tenta a API e a página oficial. Configurações e resultados da auditoria são preservados.

## Scan PHP

O botão abre o módulo php2shell.py atualizado, já com o alvo selecionado. Permite iniciar, acompanhar requisições, parar, copiar e exportar resultados JSON. O fingerprint é o modo inicial. O teste leve POST multipart de upload_progress é opcional; a janela não executa PoCs externos. Falhas e cancelamento geram resultados parciais, e o veredito do módulo não comprova execução de código.

## Validação

Foram aprovados 53 testes e 6 subtestes, além da sintaxe Bash do instalador. Os testes exercitam o código real do atualizador da tag v1.6.4 com respostas GitHub e comandos Git simulados, nos caminhos API e fallback. Também verificam instalação por fast-forward, reinício, versão exibida e abertura da janela Scan PHP. Nenhuma varredura em domínio externo foi usada na validação.
