# Cyberpm v1.4.5 — Atualização automática e explicações no relatório

## Mudanças

- O comando `cyberpm` consulta e instala releases novas automaticamente antes de abrir a interface, mesmo com configuração antiga de atualização manual.
- Removida a impressão automática de ASCII no terminal. A opção explícita `--banner` e a arte da janela inicial continuam disponíveis.
- Consulta da release com timeout de 8s; se a API falhar, tenta o redirecionamento da página oficial do GitHub.
- Falhas de consulta e de instalação aparecem no terminal, em vez de serem silenciosas.
- Relatório HTML explica cada resultado: o que foi observado, possível impacto, como validar/reproduzir, como corrigir, como retestar e qual é a evidência.
- Orientações específicas de SQLi, XSS e HSTS; inventário e acesso negado não são apresentados como exploração confirmada.

## Validação

72 testes Python aprovados. Incluem abertura sem ASCII, atualização antes da interface, fallback da consulta, rejeição de redirecionamento externo, falha de rede visível e explicações do relatório com escape de HTML. A instalação em Kali com AnonSurf não foi executada neste ambiente.

## Recuperar instalações com atualizador antigo

Na pasta da instalação, execute uma vez:

```bash
git pull --ff-only origin main
bash instalar.sh
cyberpm
```

Depois dessa atualização, basta executar `cyberpm` para consultar e instalar releases novas antes da abertura. A atualização depende de conexão com o GitHub e de um checkout Git limpo na branch main; alterações locais não são descartadas. `--sem-verificar-atualizacao` continua permitindo pular a consulta nesta execução.
