# Cyberpm 1.2 — release v1.6.6

## Scan PHP com conclusao clara

Cada resultado mostra conclusao em portugues, motivo, proximo passo e evidencias. HTTP 403 indica acesso recusado: o resultado e inconclusivo e nao equivale a ausencia de vulnerabilidade. O JSON preserva o veredito tecnico do modulo e os codigos HTTP por requisicao. O scan nao confirma execucao de codigo.

## Copia para outros programas

Copiar resultados escreve na area de transferencia real. Ctrl+C copia a selecao ou todo o resultado e Ctrl+A seleciona o texto. A interface confirma a quantidade de caracteres ou informa falha de copia. Foi removida uma substituicao global do clipboard por uma variavel interna, que impedia colar em aplicativos externos. No Windows, o backend Win32 evita uma falha nativa do Tk; no Kali e usado o Tk normal.

## Atualizacao

Em uma instalacao Git oficial limpa em main, execute cyberpm para instalar automaticamente. A interface exibe 1.2; cyberpm --versao mostra Cyberpm 1.2 (release 1.6.6). A tag de tres componentes mantem compatibilidade com o cliente v1.6.4.

## Validacao

59 testes e 6 subtestes, incluindo clipboard real com Unicode e quebras de linha, botao de copia da janela, conclusao com HTTP 403 simulado e atualizador antigo. Nenhuma varredura no dominio fornecido pelo usuario.
