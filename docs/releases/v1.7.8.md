# Cyberpm 1.10 - release v1.7.8

- Adiciona Shodan ao menu: consulta IP via InternetDB sem chave, consulta detalhada e pesquisa com chave API, filtros de pais, estado e cidade, exportacao JSON. A chave nao e gravada em arquivo. Pesquisa mostra a primeira pagina e depende do acesso da conta Shodan.
- Renomeia Teste de senhas para Brute force e adiciona Validar envio (1 senha). Essa validacao envia uma tentativa; a execucao da lista continua exigindo endpoint e formato corretos.
- Selecao de wordlist usa a janela correta e mantem a ferramenta aberta. A lista selecionada nao e misturada com senhas digitadas anteriormente.
- Mantem janelas de selecao abertas ao aplicar fases, escolher URL ou salvar wordlist; fechamento pelo X.
- Mostra motivo completo da interrupcao por HTTP 405 no painel.
- Corrige o retorno da interrupcao do John no Windows.
- Juice Shop nao incluido, conforme solicitado.

Validacao: 170 testes Python e 6 testes shell aprovados (fixtures locais); consulta real de leitura ao InternetDB; janelas abertas em previa local. Teste antigo de versao atualizado para a versao publica atual e relogio simulado do teste SQLi corrigido para nao depender do tempo do Git Bash.

Hydra, SQLmap, John, Sherlock e ExifTool nao estao instalados no Windows usado nos testes; integracoes foram verificadas com fixtures e os executaveis ainda precisam de validacao real no Kali. Pesquisa autenticada Shodan requer a chave do usuario e nao foi executada.

Execute `cyberpm` no Kali para receber a atualizacao em clones Git oficiais na branch main.
